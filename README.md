
# AUTONOVA — Automotive Services Website

A responsive automotive services website developed with HTML, CSS, and JavaScript.

**[Explore Live Website ↗](https://autonova-technical.netlify.app)**

---

## About the Project

AUTONOVA is an independent frontend portfolio project created as a fictional automotive technical inspection and vehicle services center.

The website combines a modern automotive visual identity with practical interactive features and responsive web design.

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## Key Features

- Responsive desktop and mobile layouts
- Automotive services presentation
- Technical inspection and vehicle registration information
- Appointment booking interface
- Contact form
- Interactive administrative dashboard
- Browser-based storage for demo appointments and messages

## Admin Dashboard

The project includes a demonstration administrative interface for reviewing booking requests and contact messages.

**Important:** This is a portfolio demonstration. Data is stored locally in the user's browser using LocalStorage. There is no production database, authentication system, or real appointment processing.

## Development Focus

- Semantic HTML structure
- Responsive CSS layouts
- JavaScript-based interactions
- Form handling and client-side data management
- User-friendly navigation
- Consistent visual design

## Project Type

**Independent portfolio project — fictional automotive services concept.**

Designed and developed to demonstrate frontend development skills and interactive website functionality.
